# Simplified Technical English

Write technical text so that each reader understands it in one way. Apply ASD-STE100 writing rules and controlled-vocabulary principles. Remove ambiguity without removing necessary information.

## Apply the core rules

Use one word for one part of speech and one meaning. Prefer short, direct, active sentences. Keep every necessary subject, verb, and article.

Distinguish between these text types:

- Limit procedure sentences to 20 words. Write one instruction per sentence.
- Limit description sentences to 25 words.

Apply these rules:

1. Use approved words only for their approved part of speech and meaning. If approval is uncertain, use a simple, common word with one clear meaning. Use that word consistently.
2. Make each instruction specific and concrete. Remove vague qualifiers.
3. Limit noun clusters to three words. Break longer clusters with prepositions or hyphens. For example, change `the No. 1 hydraulic system accumulator` to `the accumulator for the No. 1 hydraulic system`.
4. Use verbs only as infinitives, imperatives, simple present, simple past, simple future, or past participles used as adjectives.
5. Do not use complex verb constructions such as perfect, progressive, or modal stacks.
6. Use an `-ing` form only as a technical noun or as a modifier in a technical noun, such as `landing gear`. Do not use it as a verb tense.
7. Use active voice. In descriptions only, use passive voice when the agent is unknown.
8. Keep procedure sentences at 20 words or fewer. Keep description sentences at 25 words or fewer.
9. Do not omit a subject, verb, or article to reduce sentence length.
10. Use vertical lists for complex or conditional information.
11. Put one topic in each paragraph. Limit each paragraph to six sentences.
12. Put a warning or caution before the step that it protects. Start safety text with a clear command or condition.

## Apply controlled-vocabulary principles

Treat each approved dictionary entry as one fixed part of speech and meaning.

- Use an approved word only with its approved meaning. For example, use `CLOSE` as a verb for stopping flow or operating a circuit breaker, not for ending a meeting.
- Replace an unapproved word with an approved alternative, even when the replacement changes the sentence structure. For example, change `Before acceptance of the unit` to `Before you accept the unit`.
- Replace an unapproved meaning of an approved word. For example, change `Do not go close to the landing gear` to `Do not go near the landing gear`.
- Permit precise technical names and verbs, such as `grease`, `propeller`, `aural warning system`, `to ream`, and `to drill`, under the ASD-STE100 technical-term rules.

Do not claim full dictionary compliance unless you have checked the text against an authoritative ASD-STE100 dictionary. If no dictionary is available, apply the rules and state any vocabulary uncertainty when it is material to the request.

## Rewrite non-STE text

Use these patterns:

| Non-STE | STE |
|---|---|
| Before acceptance of the unit, do the specified test procedure. | Before you accept the unit, do the specified test procedure. |
| Rotate the cover until the jacks marked + and − are accessible. | Turn the cover until you can get access to the jacks that have + and − marks. |
| The pins should have been installed prior to pressurization. | Install the pins before you pressurize the system. |
| Do not go close to the landing gear. | Do not go near the landing gear. |
| To prevent accidents, ensure the pins are correctly installed. | To prevent accidents, make sure that the pins are installed. |

Correct these common problems:

- Keep articles and verbs when shortening text.
- Do not reuse a word with a second meaning.
- Change habitual passive constructions to direct commands. Change `The bolt is to be tightened` to `Tighten the bolt`.
- Break stacked modifiers into shorter noun groups with prepositions.
- Move warnings from paragraphs to a separate line before the protected action.

## Check the result

Before delivery, verify that:

- Each procedure sentence contains one instruction and no more than 20 words.
- Each description sentence contains no more than 25 words.
- The text uses active voice, except when an unknown agent requires passive voice in a description.
- Each verb uses an approved form without perfect, progressive, or modal stacks.
- No noun cluster contains more than three words.
- Every sentence retains its necessary subject, verb, and articles.
- Each word has one consistent meaning.
- Complex or conditional content uses a vertical list.
- Each warning starts with a command or condition and precedes the protected step.
- Each paragraph contains one topic and no more than six sentences.
